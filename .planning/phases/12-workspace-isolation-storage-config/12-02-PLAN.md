1. **DELETE /api/session/{session_id}** (`discard_session`):
   - Call `get_session(session_id, user_id=g.clerk_user_id)` to verify ownership
   - Move session JSON from SESSION_FOLDER/{session_id}.json to TRASH_FOLDER/{session_id}/{session_id}.json
   - Move upload directory from UPLOAD_FOLDER/{user_id}/{session_id}/ to TRASH_FOLDER/{session_id}/files/
   - Use `shutil.move()` for atomic same-filesystem moves
   - Set `record.deleted_at = datetime.utcnow()` in DB
   - Evict from in-memory `sessions` dict
   - Return `{"status": "trashed", "session_id": ..., "message": "Session moved to trash. Files retained for 30 days."}`
   - Return 404 if session not found or not owned by caller

2. **GET /api/sessions/trash** (`list_trash`):
   - Query `SessionRecord` where `user_id == g.clerk_user_id` AND `deleted_at IS NOT NULL`
   - Order by `deleted_at` desc
   - Return array of `{session_id, target_filename, contract_type, deleted_at, expires_at}` where `expires_at = deleted_at + 30 days`

3. **POST /api/session/{session_id}/restore** (`restore_session`):
   - Query DB directly (NOT get_session — it filters out deleted sessions)
   - Verify `record.user_id == g.clerk_user_id` and `record.deleted_at is not None`
   - Move session JSON back from TRASH_FOLDER to SESSION_FOLDER
   - Move files back from TRASH_FOLDER/{session_id}/files/ to UPLOAD_FOLDER/{user_id}/{session_id}/
   - Clear `record.deleted_at = None` in DB
   - Clean up empty trash subdirectory
   - Return `{"status": "restored", "session_id": ...}`

IMPORTANT: Add `import shutil` at top of routes.py. Use `shutil.move()` not `os.rename()` for robustness.

**Add auto-purge to server.py:**

After blueprint registration in `create_app()`, add:

```python
import shutil
import threading
import time
from datetime import datetime, timedelta

def _run_purge(app):
    """Delete trashed sessions whose deleted_at is older than 30 days."""
    from app.models.session import SessionRecord
    from app.models import db
    cutoff = datetime.utcnow() - timedelta(days=30)
    expired = (SessionRecord.query
               .filter(SessionRecord.deleted_at < cutoff)
               .all())
    for record in expired:
        trash_dir = app.config['TRASH_FOLDER'] / record.session_id
        if trash_dir.exists():
            shutil.rmtree(str(trash_dir), ignore_errors=True)
        db.session.delete(record)
    if expired:
        db.session.commit()

def _auto_purge_loop(app):
    """Background daemon that purges expired trash daily."""
    while True:
        try:
            time.sleep(86400)
            with app.app_context():
                _run_purge(app)
        except Exception:
            pass

# Run once at startup, then start daily background thread
with app.app_context():
    _run_purge(app)

purge_thread = threading.Thread(target=_auto_purge_loop, args=(app,), daemon=True)
purge_thread.start()
```

Place this AFTER `db.init_app(app)` and `app.register_blueprint(api_bp)` but BEFORE `return app`.
