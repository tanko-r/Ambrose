**server.py — DATA_DIR configuration in create_app():**
Replace the hardcoded UPLOAD_FOLDER and SESSION_FOLDER paths with DATA_DIR-derived paths:

```python
data_dir_env = os.environ.get('DATA_DIR')
if data_dir_env:
    data_dir = Path(data_dir_env)
else:
    data_dir = Path(__file__).parent / 'data'

app.config['DATA_DIR']       = data_dir
app.config['UPLOAD_FOLDER']  = data_dir / 'users'       # user-scoped subdirs
app.config['SESSION_FOLDER'] = data_dir / 'sessions'    # flat session JSON
app.config['TRASH_FOLDER']   = data_dir / 'trash'

for folder in [data_dir, app.config['UPLOAD_FOLDER'],
               app.config['SESSION_FOLDER'], app.config['TRASH_FOLDER']]:
    folder.mkdir(parents=True, exist_ok=True)
```

**Refactor get_session(session_id) to get_session(session_id, user_id=None):**

Add `user_id=None` parameter. At each of the 3 tiers, check ownership:

- Tier 1 (memory): `if user_id and data.get('user_id') and data['user_id'] != user_id: return None`
- Tier 2 (disk): Same check after loading JSON
- Tier 3 (DB): `if user_id and record.user_id and record.user_id != user_id: return None` AND `if record.deleted_at is not None: return None` (trashed sessions invisible to normal lookups)

Return None on mismatch (produces 404 to caller, not 403 — avoids leaking session existence).

**Update all 25 call sites** in route functions to pass `user_id=g.clerk_user_id`:
```python
# Before:
session = get_session(session_id)
# After:
session = get_session(session_id, user_id=g.clerk_user_id)
```

CRITICAL EXCEPTIONS — these call sites must NOT pass user_id:
- Background analysis threads (lines ~658, ~693, ~791) — they run outside request context, no `g` available. They were spawned from an authenticated request that already validated the session_id. Leave as `get_session(session_id)`.
- The `load_test_session` function itself creates the session, so the `save_session` inside it handles ownership. But add `g.clerk_user_id` as the user_id to the test session data dict so it becomes owned by the test caller.

To identify background thread calls: look for `get_session` calls inside functions that are targets of `threading.Thread` or inside `with app.app_context():` blocks. These keep `user_id=None`.
