  <name>Task 1: Create app/auth.py and add PyJWT dependency</name>
  <files>app/auth.py, requirements.txt</files>
  <action>
1. Add `PyJWT[cryptography]>=2.10.0` to `requirements.txt` (after the existing flask dependencies block).

2. Run `pip install "PyJWT[cryptography]>=2.10.0"` to install locally.

3. Create `app/auth.py` with:
   - Module-level JWKS URL resolution: read `CLERK_FRONTEND_API_URL` env var (strip trailing slash). If set, use `{url}/.well-known/jwks.json`. Otherwise fall back to `CLERK_JWKS_URL` env var, defaulting to `https://api.clerk.com/v1/jwks`.
   - Module-level `_jwks_client = PyJWKClient(url, cache_jwk_set=True, lifespan=300, cache_keys=True, max_cached_keys=16)` — singleton, created once at import time.
   - `verify_clerk_token(token: str) -> dict` function that:
     a. Gets signing key via `_jwks_client.get_signing_key_from_jwt(token)`
     b. Decodes with `jwt.decode(token, signing_key, algorithms=['RS256'], options={'verify_exp': True, 'verify_nbf': True})`
     c. Returns the decoded payload dict
     d. Catches `jwt.ExpiredSignatureError` -> raises `ValueError('Token expired')`
     e. Catches `jwt.InvalidTokenError` -> raises `ValueError(f'Invalid token: {e}')`

Do NOT create PyJWKClient inside the function — it must be module-level for caching.
  </action>

Verify `requirements.txt` contains `PyJWT[cryptography]`.

<task type="auto">
  <name>Task 2: Add before_request guard to api_bp and env-var CORS to server.py</name>
  <files>app/api/routes.py, app/server.py</files>
  <action>
1. In `app/api/routes.py`, add the following immediately after the `api_bp = Blueprint('api', __name__)` line (before any route definitions):

   - Import `g` from flask (add to existing flask import line)
   - Import `verify_clerk_token` from `app.auth`
   - Add `@api_bp.before_request` function `check_auth()`:
     a. First line: `if request.method == 'OPTIONS': return None` — let flask-cors handle preflight. This is CRITICAL; without it, all CORS preflight requests return 401 and the browser blocks everything.
     b. Extract `Authorization` header. If missing or doesn't start with `Bearer `, return `jsonify({'error': 'Authentication required'}), 401`.
     c. Strip `Bearer ` prefix to get the token.
     d. Call `verify_clerk_token(token)`. On success, set `g.clerk_user_id = payload.get('sub')`.
     e. Catch `ValueError` -> return `jsonify({'error': str(e)}), 401`.

   NOTE: This is Blueprint-level (`api_bp.before_request`), NOT app-level (`app.before_request`). The `/health` endpoint is registered on the app directly, so it is NOT affected by this guard. Do NOT add any PUBLIC_ROUTES set — all blueprint routes require auth.

2. In `app/server.py`, replace the existing CORS line:
   ```python
   CORS(app, origins=[r"http://localhost:\d+"])
   ```
   with:
   ```python
   cors_origins_raw = os.environ.get('CORS_ORIGINS', 'http://localhost:3000')
   cors_origins = [o.strip() for o in cors_origins_raw.split(',') if o.strip()]
   CORS(app, origins=cors_origins)
   ```
   The `os` module is already imported in `server.py`. The default `http://localhost:3000` covers the Next.js dev server for local development without needing to set any env var.
  </action>
