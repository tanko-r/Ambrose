  <action>
1. Install Clerk packages from the frontend directory:
   ```bash
   cd frontend && npm install @clerk/nextjs@latest @clerk/themes
   ```

2. Create `frontend/.env.local` with placeholder values:
   ```
   # Clerk Auth — get from https://dashboard.clerk.com -> API Keys
   NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_REPLACE_ME
   CLERK_SECRET_KEY=sk_test_REPLACE_ME

   # Clerk routing
   NEXT_PUBLIC_CLERK_SIGN_IN_URL=/sign-in
   NEXT_PUBLIC_CLERK_SIGN_IN_FALLBACK_REDIRECT_URL=/
   NEXT_PUBLIC_CLERK_SIGN_UP_FALLBACK_REDIRECT_URL=/
   ```

3. Verify `.env.local` is in `.gitignore` (it should be by default from create-next-app).

4. Create `frontend/src/proxy.ts` — this is the Next.js 16 middleware file (NOT middleware.ts):
   ```typescript
   import { clerkMiddleware, createRouteMatcher } from '@clerk/nextjs/server'

   const isPublicRoute = createRouteMatcher(['/sign-in(.*)'])

   export default clerkMiddleware(async (auth, req) => {
     if (!isPublicRoute(req)) {
       await auth.protect()
     }
   })

   export const config = {
     matcher: [
       // Skip Next.js internals and all static files
       '/((?!_next|[^?]*\\.(?:html?|css|js(?!on)|jpe?g|webp|png|gif|svg|ttf|woff2?|ico|csv|docx?|xlsx?|zip|webmanifest)).*)',
       // Always run for API routes
       '/(api|trpc)(.*)',
     ],
   }
   ```

IMPORTANT: Do NOT create `middleware.ts` — Next.js 16 uses `proxy.ts`. Using the wrong filename silently disables middleware.
IMPORTANT: `auth()` is async in @clerk/nextjs v6 — always use `await auth.protect()`, never `auth.protect()` without await.
  </action>
  <verify>
    Run `cd frontend && npx tsc --noEmit` — no type errors. Verify `@clerk/nextjs` appears in package.json dependencies. Verify `proxy.ts` exists at `frontend/src/proxy.ts` (not `middleware.ts`).
  </verify>
  <done>
    @clerk/nextjs and @clerk/themes installed. proxy.ts exists with clerkMiddleware protecting all routes except /sign-in. .env.local template created with placeholder keys.
  </done>
