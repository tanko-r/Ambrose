     ```python
     from app.models.session import SessionRecord

     record = db.session.get(SessionRecord, session_id)
     if record is None:
         record = SessionRecord(session_id=session_id)
         db.session.add(record)
     record.status = data.get('status', 'initialized')
     record.contract_type = data.get('contract_type')
     record.representation = data.get('representation')
     record.approach = data.get('approach')
     record.aggressiveness = data.get('aggressiveness')
     record.target_filename = data.get('target_filename')
     record.target_path = data.get('target_path')
     record.parsed_doc_path = str(data.get('parsed_doc_path', ''))
     record.precedent_path = data.get('precedent_path')
     record.revisions_count = len(data.get('revisions', {}))
     record.flags_count = len(data.get('flags', []))
     record.is_test_session = data.get('is_test_session', False)
     db.session.commit()
     ```
   - Wrap the DB block in a try/except (log warning, don't crash if DB unavailable — graceful degradation during dev).

2. **Update `get_session()`** (currently at ~line 53) to add a disk-load fallback and then a DB fallback:
   - Current code only checks `sessions` dict (in-memory). Add two fallback layers:
     a. **Disk fallback:** If not in memory, try loading from `SESSION_FOLDER/{session_id}.json`. If the JSON file exists, load it, restore `parsed_doc` from `parsed_doc_path` if that path exists, cache in `sessions` dict, and return.
     b. **DB fallback:** If not on disk either, query `SessionRecord` by primary key. If found, reconstruct a minimal session dict from the DB columns. Cache in `sessions` dict and return. If the session JSON file path can be derived, also try loading that.
   - Import `json`, `Path`, and the `_normalize_path` function (already in scope in routes.py).

3. **Add a new endpoint `GET /api/sessions`** that lists all sessions from the database:
   ```python
   @api_bp.route('/sessions', methods=['GET'])
   def list_sessions():
       from app.models.session import SessionRecord
       records = SessionRecord.query.order_by(SessionRecord.updated_at.desc()).all()
       return jsonify([{
           'session_id': r.session_id,
           'status': r.status,
           'contract_type': r.contract_type,
           'representation': r.representation,
           'target_filename': r.target_filename,
           'created_at': r.created_at.isoformat() if r.created_at else None,
           'updated_at': r.updated_at.isoformat() if r.updated_at else None,
           'revisions_count': r.revisions_count,
           'flags_count': r.flags_count,
       } for r in records])
   ```
